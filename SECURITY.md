# Security Policy

Only the latest published version of `@adistack/conform` receives security fixes.

Please do not open a public issue for vulnerabilities. Report them privately through
[GitHub Security Advisories](https://github.com/AdityaBorkar/adistack-conform/security/advisories/new).
You should get a response within a week.

`conform` runs fix commands, writes files, and calls the GitHub API with your token — reports about
any of those crossing a trust boundary (for example, a blueprint executing unexpected commands) are
especially welcome.
